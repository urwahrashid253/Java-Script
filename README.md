# JavaScript DOM Projects 

This repository contains JavaScript DOM manipulation projects built for learning and task submissions.

## Projects Included:
1. **Color Scheme Switcher:** An interactive web page that dynamically changes the background color based on user clicks.
2. **BMI Calculator:** Calculates Body Mass Index according to user-provided height and weight.
3. **Digital Clock:** A live digital clock displaying current local time updated every second.

## Tech Stack:
* HTML5
* CSS3
* JavaScript (DOM Manipulation)
